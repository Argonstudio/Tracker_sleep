# СонТрекер

**Инструмент для отслеживания режима сна** — создан для случаев хронического нарушения сна, а также для медицинского и/или исследовательского учёта.

[🇬🇧 English version](https://github.com/Argonstudio/Tracker_sleep/)

---

## ✨ Возможности

Программа строит график и таблицу ежедневных периодов сна/бордствования, учитывает следующие параметры:

| Параметр | Описание |
|----------|----------|
| **Время отхода ко сну** | Дата (день:месяц:год) и точное время |
| **Время пробуждения** | Дата (день:месяц:год) и точное время |
| **Длительность сна** | Общее количество часов сна |
| **Длительность бодрствования** | Общее количество часов без сна |
| **Сдвиг** | Насколько позже или раньше было время отхода ко сну по сравнению с предыдущим днём |
| **Сутки** | Фактическая длина цикла сон–бодрствование (субъективные сутки) |
| **Комментарий** | Необязательная заметка |

Также программа:

- Формирует Excel-таблицу и строит график.
- Отслеживает средние, минимальные и максимальные значения для:
  
  - длительности сна
  - длительности бодрствования
  - сдвига времени отхода ко сну
  - длины суток

## 🧠 Две версии

### 1. Основная версия (автоматическая)
- Рассчитана на интернет-гиков.
- Автоматически считает сном любое время вне Google Chrome длительностью более **3 часов**.
- На основе пауз в истории браузера и логов программ Windows.
- Автоматически вычисляет периоды сна и предлагает их пользователю — ошибочные записи можно удалить.
- Расчёт начинается с последней даты в Excel-файле.

### 2. Вторая версия (\`tracker_sleep1.py\`) — ручная
- Позволяет вручную вводить дату/время и добавлять комментарии.
- Чтобы использовать её: удалите основную версию и переименуйте этот файл в \`tracker_sleep.py\`.

## ⚙️ Установка

1. Создайте папку.
2. Скачайте:
   
   - файл нужной версии программы
   - \`.bat\`-файл (запускает программу двойным кликом)
   - \`requirements.txt\`
     
4. Откройте **Windows PowerShell** (Python должен быть установлен).
5. Выполните команды:

```powershell
cd нужная_папка
python -m venv .venv
./.venv/Scripts/Activate.ps1
pip install -r requirements.txt
```
